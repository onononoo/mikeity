everything on this site is also available as json, for programs, spreadsheets, and other websites. there is no server: every address below is a plain file, made by a typescript program (tools/api.ts) each time the site is built, so it works on any static host, and even from a copy on your own computer.

in addresses with {}, put a slug in its place: the same short names used in this site's own page addresses, like the-middle-ages or ibn-battuta. centuries are numbered like the database: 15 is the 15th century (the 1400s), -5 is the 5th century bce.

using it

from a web page (the files can be read from other websites):

fetch("https://your-site.vercel.app/api/people/ibn-battuta.json")
    .then(function (r) { return r.json(); })
    .then(function (p) { alert(p.name + " (" + p.dates + "): " + p.role); });

from python:

import json, urllib.request
url = "https://your-site.vercel.app/api/centuries/15.json"
for ev in json.load(urllib.request.urlopen(url))["events"]:
    print(ev["date"], ev["text"])
